Windows 백업 방법 세 가지 비교

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

Windows PC를 백업하는 공식 방법은 하나가 아니에요. 담는 대상과 저장 위치가 달라서 헷갈리기 쉬워요. 메뉴 이름은 Windows 11 기준이고, 버전에 따라 조금 다를 수 있어요. 2026년 10월에 Microsoft 지원 문서를 확인했어요.

한눈에 비교

방법 저장 위치 담는 것
Windows 백업 Microsoft 계정의 OneDrive 바탕 화면, 문서, 그림, 비디오, 음악 폴더와 설정, 설치된 앱 목록
파일 히스토리 외부 드라이브 또는 네트워크 위치 라이브러리(문서, 사진, 비디오, 음악)와 바탕 화면
OneDrive 폴더 백업 OneDrive 바탕 화면, 문서 등 중요한 Windows 폴더

Windows 백업 앱

Microsoft 지원 문서는 Windows 백업을 파일, 테마, 설정부터 설치된 앱, Wi-Fi 정보까지 백업하는 원스톱 솔루션이라고 소개해요. 개인 Microsoft 계정으로 로그인해야 하고, 회사나 학교 계정은 작동하지 않는다고 안내해요. 무료 Microsoft 계정에는 5GB의 OneDrive 저장소가 제공되고 더 필요하면 구매할 수 있어요. 배경 화면, 색, 테마 같은 개인 설정은 OneDrive 로그인과 남은 저장소가 필요하고, 저장소가 부족하면 백업되지 않아요.

파일 히스토리

Microsoft 지원 문서는 파일 히스토리가 문서, 사진, 비디오, 음악 같은 기본 라이브러리와 사용자가 만든 라이브러리를 외부 드라이브나 네트워크 위치에 정기적으로 백업한다고 설명해요. 데스크톱 같은 필수 폴더도 자동으로 백업하고, 다른 폴더는 라이브러리에 추가해서 포함해요. 파일을 실수로 삭제하거나 원치 않게 바꿨을 때 이전 버전으로 복원할 수 있어요.

OneDrive 폴더 백업

OneDrive 설정의 동기화 및 백업 탭에서 백업 관리를 열고, 백업되지 않음으로 표시된 폴더를 켜면 돼요. 폴더를 백업하면 파일이 OneDrive에 동기화되어, OneDrive에 로그인한 다른 기기에서도 같은 파일을 볼 수 있어요. 백업을 끌 때는 파일을 OneDrive에만 둘지 내 PC에만 둘지 고르게 돼요.

어떤 것을 고를까요

  • 외부 드라이브나 네트워크 위치에 정기 백업을 두고 싶다면 파일 히스토리를 봐요.
  • 새 PC로 옮길 때 설정과 앱 목록까지 챙기고 싶다면 Windows 백업을 봐요. 개인 Microsoft 계정이 필요해요.
  • 여러 기기에서 같은 폴더의 파일을 쓰려면 OneDrive 폴더 백업을 봐요.
  • 저장 위치가 서로 다른 방법을 함께 쓰면 사본을 여러 곳에 두는 3-2-1 원칙에 가까워져요.

복원할 때는 어떻게 되나요

Windows 백업과 파일 히스토리는 되돌리는 방식도 달라요.

방법 복원 방법
Windows 백업 새 PC를 사거나 Windows를 다시 설치할 때 백업할 때 쓴 Microsoft 계정으로 로그인하면 백업이 있는지 확인하고 복원할지 물어요. 백업한 PC가 둘 이상이면 추가 옵션에서 복원할 백업을 골라요
파일 히스토리 파일 탐색기에서 폴더를 오른쪽 클릭해 이전 버전 복원을 열고 시점을 골라요
OneDrive 폴더 백업 같은 계정으로 OneDrive에 로그인하면 파일을 언제든 다시 쓸 수 있어요

Windows 백업으로 복원하면 앱 핀이 원래 위치에 돌아와요. Microsoft Store 앱은 핀을 눌러 설치하고, Store에 없는 앱은 설치 파일을 받으러 웹으로 이동해요. 앱 자체가 통째로 복사되는 건 아니라는 점이 목록의 한계예요.

빠지는 것, 막히는 것

  • Windows 백업의 개인 설정(배경 화면, 색, 테마, 시작 레이아웃)은 OneDrive 로그인과 여유 저장소가 있어야 하고, 저장소가 부족하면 백업되지 않아요.
  • Windows 백업은 회사나 학교 계정에서는 작동하지 않아요.
  • OneDrive 폴더 백업을 끌 때 파일을 OneDrive에만 둘지 컴퓨터에만 둘지 선택해요. 컴퓨터에만 두기를 고르면 OneDrive에서 제거된다고 안내해요.
  • 파일 히스토리는 라이브러리에 없는 폴더를 따로 추가해야 담겨요.

세 방법과 3-2-1 원칙

사본 3개, 매체 2종, 1개는 다른 장소라는 원칙에 비춰 보면 Windows 백업과 OneDrive 폴더 백업은 둘 다 클라우드 한 곳이고, 파일 히스토리만 집 안의 외부 드라이브예요. 그러니 클라우드 쪽 하나와 파일 히스토리를 함께 쓰는 조합이 서로 다른 매체를 확보하는 가장 직접적인 방법이에요(제안). 어느 한 방법이 원본 PC 고장, 계정 문제, 삭제 사고를 모두 막아 준다고 Microsoft가 보장하는 것은 아니에요.

핵심 정리

  • Windows 백업, 파일 히스토리, OneDrive 폴더 백업은 저장 위치와 대상이 달라요.
  • Windows 백업은 개인 Microsoft 계정 기준이고 무료 OneDrive 저장소는 5GB예요.
  • 하나에만 의존하지 말고 서로 다른 위치에 사본을 두세요.

  2. Microsoft 지원 파일 히스토리를 사용하여 백업 및 복원
  3. Microsoft 지원 OneDrive를 사용하여 폴더 백업
