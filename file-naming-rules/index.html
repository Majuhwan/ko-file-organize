파일 이름 규칙 정하는 법

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 10월 다시 확인 예정

"최종", "최종2", "진짜최종"이 쌓이면 어느 것이 마지막인지 알 수 없어요. 이름 규칙을 한 번 정해 두고 같은 방식으로 계속 쓰면 이런 일이 줄어요.

공식 안내가 드는 이름 재료

Google 드라이브 고객센터는 파일 이름을 짧고 간단하며 의미 있게 짓고, 날짜를 추가하거나 해시태그나 숫자를 쓸 수도 있다고 해요. 모든 항목을 추적하는 재료로는 세 가지를 예로 들어요.

재료 Google 공식 예시
날짜 YYYY-MM_DD_Project_Notes
프로젝트 이름 Book Report_The Forest
키워드 Math Homework_Chapter 5

미국 의회도서관도 사진마다 설명이 되는 파일 이름을 붙이라고 안내해요. 카메라가 붙인 번호만 있으면 무슨 사진인지 알기 어렵기 때문이에요.

내 규칙으로 정해 둘 것

공식 문서가 순서나 구분 기호까지 정해 주지는 않아요. 아래 네 가지를 내가 한 번 정해서 적어 두면 돼요.

  1. 어떤 재료를 쓸지: 날짜, 프로젝트, 키워드 중 고르기
  2. 재료의 순서: 예를 들어 날짜, 프로젝트, 키워드 순
  3. 날짜 표기: 연도 4자리, 월과 일 2자리 같은 식으로 한 가지
  4. 구분 기호: 밑줄이나 하이픈 중 하나
정리 전 규칙을 적용한 예시
새 문서 최종2 2026-10-19_가계부_10월
IMG_4821 2026-08-14_제주_해변

오른쪽 열은 위 네 가지를 정한 가상의 예시예요.

OneDrive에서 피해야 할 문자

클라우드와 함께 쓸 계획이라면 서비스의 제한도 알아 두세요. Microsoft 지원 문서는 가정용과 직장 또는 학교용 OneDrive의 파일과 폴더 이름에 " * : < > ? / \ | 문자를 허용하지 않는다고 해요. 이름 앞뒤 공백도 쓸 수 없어요. 이런 문자가 있으면 파일과 폴더가 동기화되지 않을 수 있으니 올리기 전에 지우거나 바꾸라고 안내해요. 같은 문서에는 Mac용 OneDrive가 2025년 1월 28일부터 잘못된 문자를 지원한다는 소식도 적혀 있어요.

OneDrive에서 쓸 수 없는 이름

Microsoft 지원 문서는 다음 이름으로는 파일이나 폴더를 만들 수 없다고 해요.

  • .lock, CON, PRN, AUX, NUL
  • COM0부터 COM9, LPT0부터 LPT9
  • vti (이름의 어느 곳에도 쓸 수 없음)
  • desktop.ini
  • ~$로 시작하는 이름

일상적인 한글 이름에서는 거의 만나지 않지만, 영문 약어로 이름을 지을 때는 확인해 보세요.

이름이 좋으면 이럴 때 편해져요

Google 드라이브 고객센터는 중복 파일을 찾는 방법으로 파일을 이름순으로 정렬하고 목록 보기로 확인하라고 안내해요. 이름이 비슷한 파일이 나란히 붙어서 같은 파일을 두 번 저장한 경우를 알아보기 쉬워요. 이름에 날짜가 앞에 있으면 날짜순으로, 프로젝트가 앞에 있으면 프로젝트별로 붙는다는 점은 이름순 정렬의 성질이라 규칙을 정할 때 순서를 고르는 근거가 돼요.

하고 싶은 일 이름에서 먼저 둘 재료
시간 순서대로 보기 날짜 (연도 4자리, 월·일 2자리처럼 자릿수를 맞춰야 순서가 안 꼬여요)
한 일의 자료를 모아 보기 프로젝트 이름
사진·문서를 종류별로 찾기 키워드

이 표는 정렬 방식에 따른 제안이고, 어느 쪽이 맞다는 공식 기준은 없어요. Google도 파일을 정리하는 올바른 방법은 없다고 밝혀요.

이름만으로 모자랄 때

Google 드라이브는 이름 외에도 파일과 폴더에 설명을 붙일 수 있어요. 파일을 오른쪽 클릭해 파일 정보, 세부정보를 누르고 측면 패널 아래로 내려가 설명을 적어요. 중요한 항목은 별표를 달면 빠르게 열 수 있고, 폴더에는 색상으로 라벨을 붙일 수 있어요. 이름은 짧게, 부연은 설명에 두는 식으로 나누면 이름이 길어지는 걸 막아요.

클라우드와 함께 쓸 때 더 챙길 것

  • 같은 폴더를 여러 PC나 웹에서 동시에 고치면 OneDrive에서 동기화 충돌이 생길 수 있어요. Microsoft는 충돌을 줄이려면 편집한 파일을 새로운 이름이나 고유한 이름으로 바꿔 다시 저장하라고 안내해요. 규칙에 편집본을 구분하는 재료(날짜 등)를 넣어 두면 이럴 때 쉬워요.
  • 폴더 안의 폴더가 깊어지면 경로가 길어져요. OneDrive 폴더 백업 문서는 파일 이름을 포함한 전체 경로가 Windows 기준 260자 미만이어야 한다고 안내해요. 이름을 길게 짓는 습관이 있다면 이 한도에 가까워질 수 있어요.
  • Mac에서 쓸 때도 위 금지 문자 제한은 똑같이 적용돼요. 대소문자를 구분하도록 포맷한 디스크 볼륨은 OneDrive에서 지원되지 않아요.

핵심 정리

  • 날짜, 프로젝트 이름, 키워드 중 쓸 재료와 순서를 정해 계속 같은 방식으로 써요.
  • 날짜 표기와 구분 기호는 한 가지로 통일해요.
  • OneDrive 기준으로 " * : < > ? / \ | 문자와 앞뒤 공백은 이름에 쓰지 않아요.
