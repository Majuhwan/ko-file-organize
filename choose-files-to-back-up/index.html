백업할 파일 고르는 기준과 메일 보관

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

백업할 파일은 컴퓨터의 모든 파일이 아니라, 다시 얻을 수 없는 것부터 고르세요. 미국 의회도서관의 개인 보관 안내는 사진, 비디오, 이메일 모두 어디에 있는지 찾는 단계 다음에 무엇이 중요한지 고르는 단계를 둬요. 의회도서관 페이지에는 작성 시점이 적혀 있지 않아 DVD, CD 같은 매체 예시는 지금 쓰는 매체로 바꿔 읽으세요.

의회도서관의 선택 기준

사진 안내는 특히 중요하다고 생각하는 사진을 고르라고 하고, 몇 장이든 상관없다고 해요. 사진은 유일해서 잃어버리면 그 안의 정보를 다시 얻을 수 없다는 점이 이유로 적혀 있어요. 같은 사진이 여러 버전이면 품질이 가장 높은 것을 저장하라고 해요. 파일 종류별 등급표는 없어서, 아래 표는 이 기준을 가정에서 쓰기 쉽게 풀어 본 예시예요.

우선순위 기준 예시
먼저 다시 얻을 수 없는 것 직접 찍은 사진과 영상, 직접 쓴 글
다음 다시 받으려면 번거로운 것 서류 파일, 메일 첨부 파일
나중 다시 내려받을 수 있는 것 설치 파일, 내려받은 자료

메일은 프로그램 밖에 파일로 저장해요

의회도서관은 이메일이 종이 편지처럼 중요한 사건과 거래, 관계를 기록한다고 설명해요. 메일 프로그램은 정보를 오래 보관하려고 만든 것이 아니라서 언제든 바뀌거나 지원이 끝날 수 있으니, 보관하려면 프로그램과 분리해서 저장하라고 안내해요.

  1. 메일 계정을 모두 찾아요. 계정마다 폴더나 별도 묶음을 확인하고 보관 처리한 메시지도 포함해요.
  2. 오래 남길 가치가 있는 메시지를 골라요. 몇 통이든 상관없어요.
  3. 고른 메시지에 딸린 첨부 파일도 저장해요.
  4. 몇 통이면 메일 프로그램의 다른 이름으로 저장 기능으로 한 통씩 파일로 내보내요. 많다면 프로그램의 자동 내보내기 기능을 찾아보세요.
  5. 가능하면 열린 형식으로 저장하고, 제목, 보낸 사람, 받는 사람, 시간과 날짜가 담긴 헤더 정보도 함께 남겨요.

저장한 메일과 첨부 파일에는 설명이 되는 파일 이름을 붙이고, 폴더 구조와 짧은 요약도 적어 둬요. 요약 사본은 중요한 서류와 함께 안전한 곳에 두라고 안내해요. 아래는 이름을 붙이는 가상의 예시예요.

항목 예시
폴더 메일 보관 / 2026 / 이사
메일 파일 2026-10-19_이사견적_업체A
첨부 파일 2026-10-19_이사견적_업체A_견적서

고른 뒤에 해야 할 일

고른 파일은 이름과 폴더로 정리하고 최소 두 벌을 서로 다른 매체에 복사해요. 의회도서관은 최소 1년에 한 번 열어 읽을 수 있는지 확인하고, 5년마다 또는 데이터 손실을 막아야 할 때 새 매체로 복사본을 만들라고 해요. 선택은 한 번으로 끝나지 않으니 새로 생긴 중요한 파일이 있을 때 목록에 더하면 돼요.

백업 대상 목록 만들기

고른 파일을 표 하나로 적어 두면 빠뜨림이 줄어요.

중요한 메일 메일 계정 아니오 날짜 기입

의회도서관도 사진 목록을 중요한 서류와 함께 안전한 곳에 두라고 안내해요. 이 표도 파일 자체와 따로 한 부 더 보관하세요.

핵심 정리

  • 모두가 아니라 다시 얻을 수 없는 파일부터 골라요.
  • 같은 내용이 여러 버전이면 품질이 가장 높은 것을 남겨요.
  • 메일은 첨부 파일, 헤더 정보와 함께 메일 프로그램 밖에 저장해요.
