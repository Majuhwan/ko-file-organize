파일·사진 정리

폴더 구조, 백업, 중복 파일, 사진 정리. 공식 기관 자료를 확인해 정리합니다.

  • Mac Time Machine 시작과 백업 주기 확인

    Time Machine은 Mac의 파일을 외장 저장장치에 자동으로 백업해요. 디스크 용량 기준과 설정 경로, 백업 주기 구조, 멈췄는지 확인하는 법을 Apple 문서로 정리했어요.

  • Windows 백업 방법 세 가지 비교

    Windows에는 Windows 백업 앱, 파일 히스토리, OneDrive 폴더 백업이 있어요. 각각 무엇을 어디에 담는지 Microsoft 지원 문서를 기준으로 비교했어요.

  • 백업할 파일 고르는 기준과 메일 보관

    모든 파일을 백업하기 어렵다면 되찾을 수 없는 것부터 고르세요. 의회도서관의 선택 기준과 메일을 프로그램 밖에 파일로 저장하는 순서, 대상 목록 만드는 법을 정리했어요.

  • 동기화와 백업은 어떻게 다를까

    iCloud 사진을 쓰면 한 기기에서 지운 사진이 다른 기기에서도 지워져요. Apple, Google 공식 문서로 동기화의 삭제 방식과 백업의 필요성을 설명해요.

  • 가족 사진 정리 방법 다섯 단계

    가족 사진은 위치 확인, 중요한 사진 고르기, 이름과 태그 붙이기, 사본 보관, 연 1회 점검 순서로 정리해요. 의회도서관 안내에 카메라 옮기기와 앨범 구분을 더했어요.

  • 파일 이름 규칙 정하는 법

    파일 이름에 날짜, 프로젝트, 키워드를 넣고 순서를 통일하는 방법과 OneDrive에서 쓸 수 없는 문자를 Google, 의회도서관, Microsoft 안내로 정리했어요.

  • 3-2-1 백업을 개인 파일에 적용하는 법

    3-2-1 백업은 사본 3개, 저장매체 2종, 오프사이트 1곳으로 두는 방식이에요. KISA와 의회도서관, CISA 안내를 개인 파일에 맞춰 풀고 집 밖 보관 후보를 비교했어요.

  • 폴더 구조 처음 만들 때 지킬 세 가지

    폴더를 처음 만들 때 단계는 간단하게, 이름은 알아보기 쉽게, 구조는 짧은 설명으로 남기는 세 가지 원칙을 Google, 의회도서관, Apple 안내로 정리했어요.
