Mac Time Machine 시작과 백업 주기 확인

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

Mac에는 Time Machine이라는 백업 기능이 있어요. 외장 저장장치만 연결하면 앱, 음악, 사진, 이메일, 문서 같은 파일을 자동으로 백업해요. 이 글은 Apple 지원 문서(2026-07-09 게시)를 기준으로 설정 과정과 백업 주기를 정리했어요. 설정 경로는 macOS Ventura 13 이후 기준이고, 이전 버전은 Apple 문서의 해당 안내를 보세요.

준비물과 용량 기준

USB 드라이브나 Thunderbolt 드라이브 같은 외장 저장장치가 필요해요. Apple은 Mac의 저장 용량보다 두 배 이상 큰 저장장치를 쓰라고 안내해요. Mac이 1TB라면 백업 디스크는 2TB 이상이어야 해요. 저장 공간이 더 필요하면 Mac이 알려 줘요. 그리고 Time Machine 백업 디스크는 다른 파일을 저장하는 용도로 쓰지 말고 백업 전용으로 쓰라고 해요.

설정하는 순서

  1. 외장 저장장치를 Mac에 연결해요.
  2. Apple 메뉴에서 시스템 설정을 선택해요.
  3. 사이드바에서 일반을 누르고 오른쪽의 Time Machine을 눌러요.
  4. 백업 디스크 추가 또는 + 버튼을 눌러요.
  5. 연결한 저장장치를 선택하고 디스크 설정을 눌러요.

저장장치를 지울 것인지 묻는 메시지가 나올 수 있어요. 기존 파일이 들어 있다면 지워도 되는지 먼저 확인하세요. 다른 컴퓨터에서 만든 기존 백업을 이 Mac의 백업에 포함할지 묻는 메시지가 나오면, 포함하면 그 백업이 현재 Mac 백업의 일부가 돼요. 백업 암호화를 켜면 암호를 만들게 되고, 나중에 복원할 때 이 암호가 필요해요. 설정이 끝나면 Mac이 바로 첫 백업을 시작해요.

백업은 어떻게 쌓이나요

Time Machine은 지난 24시간은 시간별, 지난달은 일별, 그 이전의 모든 달은 주별 백업을 자동으로 만들어요. 백업 디스크가 가득 차면 가장 오래된 백업부터 삭제돼요. 첫 백업은 오래 걸릴 수 있지만 그동안 Mac을 계속 쓸 수 있고, 이후에는 이전 백업 이후 바뀐 파일만 백업해서 더 빨라요.

백업 빈도를 바꾸려면 macOS Ventura 13 이후에서 메뉴 막대의 Time Machine 메뉴에서 Time Machine 설정 열기를 선택하고, 옵션을 눌러 백업 빈도 메뉴에서 고르세요. 바로 백업하고 싶다면 같은 메뉴에서 지금 백업을 선택해요.

주기를 어떻게 정할까

KISA 수칙(2025-07-17)은 일간, 주간, 월간 백업을 자동화해서 실수와 누락을 막으라고 해요. 기업용 수칙이지만 집에서도 파일이 얼마나 바뀌는지에 따라 같은 원리를 쓸 수 있어요. 아래는 정리 방법의 제안이고 공식 수치가 아니에요.

파일 종류 바뀌는 빈도 방향
쓰고 있는 문서 매일 시간별 백업을 그대로 두기
새로 찍는 사진 며칠에 한 번 정기 백업과 함께 원본을 폴더에 모으기
오래된 사진 보관본 거의 안 바뀜 바뀔 때만 다시 확인

Windows는 파일 히스토리를 켜 두면 파일과 폴더를 지속적으로 모니터링해 외부 드라이브나 네트워크 위치에 정기적으로 백업해요. 문서, 사진, 비디오, 데스크톱 같은 필수 폴더는 자동으로 들어가요. 두 방식 모두 백업 장치가 연결되어 있어야 해요.

멈췄는지 확인하는 법

메뉴 막대의 Time Machine 메뉴 상단에는 현재 백업의 진행 상황 또는 최근 백업의 날짜와 시간이 표시돼요. 그 날짜가 며칠째 같다면 점검할 때예요. 메뉴가 보이지 않으면 메뉴 막대 설정이나 제어 센터 설정에서 Time Machine 상태를 표시하도록 켜세요. 흔한 이유는 세 가지예요. 백업 디스크가 분리되어 있거나, 저장 공간이 부족하거나, 백업을 중지 또는 건너뛰기로 해 두었을 때예요.

백업 디스크를 뺄 때는 먼저 추출하거나 Mac을 종료하라고 Apple은 안내해요. 나중에 다시 연결하면 Time Machine이 자동으로 백업 일정을 이어서 진행해요.

핵심 정리

  • 백업 디스크는 Mac 저장 용량의 두 배 이상, 백업 전용으로 써요.
  • 시간별, 일별, 주별로 쌓이고 가득 차면 오래된 것부터 지워져요.
  • 메뉴의 최근 백업 날짜로 멈췄는지 가끔 확인하고, 암호화를 켰다면 암호를 따로 적어 두세요.
